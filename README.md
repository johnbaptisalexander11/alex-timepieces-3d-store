# Alex Timepieces 3D Store

A 3D product showcase website: a variant carousel, colour changes, and scroll-driven animations for a watch, built with Three.js.

This is a practice project. The brand, prices and specifications are examples and nothing is for sale.

## Run locally

Serve the folder with any static server, for example:

    npx serve .

## Built with

- Three.js r147 (GLTFLoader, RoomEnvironment), loaded from a CDN
- Plain HTML, CSS and JavaScript in `index.html`
